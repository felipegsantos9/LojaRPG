##  Sobre o projeto

A **Quest & Dados** é uma aplicação web inspirada em lojas virtuais, desenvolvida com foco no universo de **RPG de mesa**.

A proposta do projeto é apresentar uma experiência de navegação para usuários interessados em produtos como dados, livros, miniaturas e acessórios para RPG.

A interface foi planejada para facilitar a navegação pelo catálogo e destacar diferentes categorias e produtos.

## Funcionalidades

*  Página inicial
*  Catálogo de produtos
*  Categorias de produtos
*  Busca de produtos
*  Produtos em destaque
*  Carrinho de compras
*  Favoritos
*  Páginas de produtos
*  Interface adaptada para diferentes tamanhos de tela
*  Navegação entre as páginas

## Tecnologias utilizadas

* **HTML5** — estrutura e organização das páginas
* **CSS3** — estilização, layout e responsividade
* **JavaScript** — interações e funcionalidades da interface

##  Objetivos do projeto

O projeto foi desenvolvido com o objetivo de colocar em prática conhecimentos de desenvolvimento web, trabalhando principalmente com:

* Estruturação de páginas utilizando HTML5
* Criação de layouts com CSS3
* Desenvolvimento de interfaces responsivas
* Organização de componentes visuais
* Experiência e navegação do usuário
* Desenvolvimento de uma interface inspirada em e-commerce
